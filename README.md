# 🚀 RYBack

RYBack is an experimental app and website project created as a prototype.

## ✨ Features

* 🔐 Email login
* 🌐 Google sign-in
* 👤 Guest mode
* ⚙️ Settings
* 🛡️ RYBack Protection
* 🚀 RYBack Apps
* 📱 Website and installed-app modes

## 🛡️ RYBack Protection

RYBack includes a protection feature with:

* ✅ Protected status
* ⚠️ Threat detection
* ❌ Protection notification
* 🔄 Enable/disable control
